# 06 — UI

One page, `static/index.html`, served at `GET /`. No frontend build and no component framework. The page is usable at 1280px wide and at 390px wide: the three columns stack on the narrow width.

## Header

Title: **Go-live**. One sentence under it: "Provisions a Fieldbase tenant from the signed contract. An operator marks the account live."

Controls:

- Scenario select: Northwind, Contoso, Fabrik, Retry Northwind. Default Northwind.
- Mode select: Fake, Live. Default Fake.
- Button: **Run**.
- After a run, if the tenant is on screen: **Record SSO metadata** and **Mark live**.

Disable Run while a request is in flight. Disable Record SSO metadata unless the loaded tenant's contract has `ssoRequired` true and SSO is not ready. Disable Mark live unless `status` is `ready_for_review`.

## Columns

**Contract.** Customer, seats, region, modules by label (Projects, Time, Billing), admins as name plus email, SSO required yes or no, metadata present yes or no. Populated from the run response, which includes the contract.

**Trace.** One row per step, in order: step index, tool name, HTTP status, error code or "ok". A row with `MODULE_NOT_PURCHASED` uses a light red background. Replayed steps show the word Replayed when `Idempotent-Replayed` was true. The step payload includes that boolean.

**Checklist.** Status, live yes or no, and each checklist item with ok or not. Open tasks show their title. `final_text` shows under the list when it is non-empty.

## Requests

- `POST /api/demo/run` with `{ "scenario", "mode" }`.
- `POST /api/demo/tenants/{tenantId}/sso-metadata`.
- `POST /api/demo/tenants/{tenantId}/go-live`.

On a problem body, show `code` and `detail` above the columns. Do not clear the last successful tenant when a later operator click fails.

Retry Northwind before the first Northwind run shows the API error. The page does not special-case that beyond displaying `code`.

Live mode without configuration shows `LIVE_MODEL_NOT_CONFIGURED` and does not pretend to stream.

## Visual rules

Use a white background, a sans-serif font, and black text. Red is only for a rejected tool row. Green is only for a checklist item with `ok: true`. Do not add a chart, a marketing section, or a fake accuracy number.

## Not in the page

No login form, no token field, no contract editor, no free-text chat. The scenario message is fixed by `fixtures/scenarios.json` and is shown as read-only text above the trace so a reviewer can see that Contoso's message mentions Billing.
